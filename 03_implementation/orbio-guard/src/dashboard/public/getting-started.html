Developer onboarding

From zero to a guarded request.

You do not need an Orbio account key. You need one Guard agent token from your operator, an allowed model, and the Guard API URL.

Never ask for or paste the shared Orbio gateway key. Your credential begins with og_agent_, not sk-orbio-.
01

Request access

Ask for one controlled identity.

Send your Guard operator these four details:

Project: customer-support Models: openai/gpt-4o-mini Daily budget: $2.00 Maximum per request: $0.10

The operator creates the agent in the dashboard and sends its token once. Store it immediately in your password manager or development secret store.

02

Terminal check

Prove the connection first.

macOS or Linux:

export ORBIO_GUARD_AGENT_TOKEN="og_agent_..."

curl https://api.guard.larkvine.org/v1/chat/completions \
  -H "Authorization: Bearer $ORBIO_GUARD_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-4o-mini",
    "messages": [{"role": "user", "content": "Reply with: connected"}]
  }'

Windows PowerShell:

$env:ORBIO_GUARD_AGENT_TOKEN = "og_agent_..."

$headers = @{
  Authorization = "Bearer $env:ORBIO_GUARD_AGENT_TOKEN"
  "Content-Type" = "application/json"
}
$body = @{
  model = "openai/gpt-4o-mini"
  messages = @(@{ role = "user"; content = "Reply with: connected" })
} | ConvertTo-Json -Depth 4

Invoke-RestMethod -Method Post `
  -Uri "https://api.guard.larkvine.org/v1/chat/completions" `
  -Headers $headers -Body $body

A successful response proves your token, model policy, budget, Guard, and Orbio route all work.

03

Application code

Change the base URL, not your workflow.

JavaScript / TypeScript

import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.ORBIO_GUARD_AGENT_TOKEN,
  baseURL: "https://api.guard.larkvine.org/v1",
});

const result = await client.chat.completions.create({
  model: "openai/gpt-4o-mini",
  messages: [{ role: "user", content: "Hello" }],
});

Python

import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["ORBIO_GUARD_AGENT_TOKEN"],
    base_url="https://api.guard.larkvine.org/v1",
)

result = client.chat.completions.create(
    model="openai/gpt-4o-mini",
    messages=[{"role": "user", "content": "Hello"}],
)
Keep tokens outside source control. Add .env to .gitignore, use your deployment platform's secret manager in production, and never put a token in frontend browser code.
04

IDEs and agent tools

Launch the tool with Guard configured.

Codex

Use the Responses API.

Export the token, then add this to ~/.codex/config.toml:

model = "openai/gpt-4o-mini"
model_provider = "orbio_guard"

[model_providers.orbio_guard]
name = "Orbio Guard"
base_url = "https://api.guard.larkvine.org/v1"
env_key = "ORBIO_GUARD_AGENT_TOKEN"
wire_api = "responses"
requires_openai_auth = false
supports_websockets = false

Guard translates Codex Responses requests, including function tools, to Orbio's available Chat Completions route.

Claude Code

Use the Messages API.

export ORBIO_GUARD_AGENT_TOKEN="og_agent_..."
export ANTHROPIC_BASE_URL="https://api.guard.larkvine.org"
export ANTHROPIC_AUTH_TOKEN="$ORBIO_GUARD_AGENT_TOKEN"
export ANTHROPIC_MODEL="anthropic/claude-sonnet-4"

claude
Cursor

Use a custom OpenAI provider when available.

  1. Open Cursor Settings → Models.
  2. Enable the OpenAI-compatible or custom provider.
  3. Base URL: https://api.guard.larkvine.org/v1
  4. API key: your og_agent_... token.
  5. Model: one allowed by your policy.

If your Cursor version does not expose a base URL, use Codex, Claude Code, or your application SDK.

VS Code / JetBrains

Use the integrated terminal.

  1. Open the project in your IDE.
  2. Open its integrated terminal.
  3. Export ORBIO_GUARD_AGENT_TOKEN.
  4. Run your app, Codex, or Claude Code from that terminal.

For run configurations, add the token as a local environment variable. Do not commit workspace settings containing it.

05

Understand errors

Guard failures are actionable.

401 INVALID_AGENT_TOKEN
The token is missing, mistyped, disabled, or no longer valid. Ask the operator for a new identity.
403 MODEL_NOT_ALLOWED
Choose an allowed model or ask the operator to change the policy.
403 AGENT_PAUSED / AGENT_DISABLED
The operator stopped this identity. Do not bypass Guard; contact them.
429 REQUEST_LIMIT_EXCEEDED
The request ceiling is lower than Guard's reservation. Ask for an appropriate ceiling.
429 DAILY_BUDGET_EXCEEDED
The agent used its UTC daily allowance. Wait for rollover or request a policy change.

Ready

One token. One policy. No shared key.
