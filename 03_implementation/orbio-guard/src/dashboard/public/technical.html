03 · Atomic accounting

Reserve. Forward. Reconcile.

1

Reserve

Confirmed plus in-flight spend is checked under a cross-process lock.

2

Forward

The vault key is loaded only after identity and policy succeed.

3

Confirm

Provider usage replaces the reservation using integer micro-dollars.

05 · Fail closed

Crashes do not reopen the budget.

Stale reservations are conservatively confirmed by default because an interrupted provider request may still have been billed.

Metadata only

Audit without prompt logging.

  • Agent and request IDs
  • Model and policy decision
  • Reserved and confirmed cost
  • Key events by fingerprint
  • No prompts, responses, or secrets
